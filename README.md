# 🌧️ Rain Alert

A Python application that checks the weather forecast using the OpenWeather API and sends an email alert when rain is expected.

## Features

* Checks upcoming weather conditions
* Detects possible rain
* Sends an email alert automatically
* Keeps API keys and email credentials secure using environment variables

## Technologies Used

* Python
* Requests
* OpenWeather API
* SMTP
* Python Dotenv

## Example

If rain is expected, the program sends:

> It will rain today.
> Bring an umbrella! ☔
